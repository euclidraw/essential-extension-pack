# 그룹·프레임 기능 로드맵

Figma의 그룹과 프레임은 캔버스의 계층 컨테이너다. [그룹과 프레임의 차이](https://help.figma.com/hc/en-us/articles/360039832054-The-difference-between-frames-and-groups)와 [프레임 기능](https://help.figma.com/hc/en-us/articles/360041539473-Frames-in-Figma-Design)을 행동 기준으로 삼는다. 아래 항목은 목표이며 완료 표시가 없는 기능은 아직 제공하지 않는다.

## 현재 제공

- [x] 그룹 생성과 해제, 계층 참조, 선택 구성원의 그룹 이동, 클릭으로 내부 선택과 점선 윤곽.
- [x] 프레임 생성, 선택 객체의 수동 소속 지정, 제목 편집과 SVG 출력.
- [x] 프레임 이동 시 중첩 그룹·프레임과 자손을 함께 이동. 미리보기는 임시 계층에 두고 확정은 한 Undo 배치로 처리.

## 1. 계층 선택과 기하

- [ ] 클릭 기반 그룹 선택 및 Escape 복귀를 Shift 선택·마퀴·잠금·분할 뷰까지 일관되게 확장. Enter로 내부에 진입하는 동작.
- [ ] 그룹의 바운딩을 자손 기하에서 파생하고, 그룹 자체의 위치·크기를 자손 변화에 따라 정본에 쓰지 않음. 선택 표시와 변형 대상을 분리해 프레임 이동 후에도 프레임 하나가 선택된 상태를 유지.
- [ ] 그룹 이동·크기 조절·회전과 중첩 그룹의 변형을 하나의 미리보기와 Undo로 처리. 회전된 자식, 연결선, 텍스트와 이동할 수 없는 자식의 정책을 명시하고 테스트.
- [ ] 순환·삭제·동시 재부모화에 대한 결정론적 계층 투영과 확장 비활성화 시 데이터 보존.

## 2. 프레임 편집

- [ ] F 도구로 드래그 생성, 크기 프리셋과 제목·배경·테두리·모서리 속성.
- [ ] 객체를 프레임 안팎으로 드래그해 재부모화. 회전된 경계, 중첩 대상, 다중 선택, 동시 편집, 단일 Undo를 정의.
- [ ] 프레임 크기 조절 시 자식은 기본적으로 원래 크기를 유지하고 제약에 따라 위치와 크기를 조정. 맞춤 크기 명령.
- [ ] Clip content: DOM·GPU·SVG·출판·히트 테스트에서 같은 중첩 클리핑과 단일 Z축을 유지. 개별 프레임 배경만 클리핑하는 방식으로 완료 처리하지 않음.
- [ ] 복제·복사·붙여넣기·삭제·되돌리기 시 전체 하위 트리와 참조를 정확히 처리.

## 3. 레이아웃과 출판

- [ ] 수평·수직·그리드 자동 레이아웃, 간격·패딩·정렬·wrap과 fixed/hug/fill 크기 정책. 결과 기하는 파생하고 사용자 의도만 정본에 저장.
- [ ] 레이아웃 가이드, 중첩 프레임 개별 SVG와 다중 페이지 출판. 효과와 채우기 종류는 별도 확장 계약으로 추가.

## 완료 검증

각 단계에서 실제 Rust CRDT·단일 Undo, 원격 편집과 충돌, IME, 읽기 시 정본 변경 없음, 확장 비활성화와 참조 보존, 화면과 순수 SVG의 일치, 숨겨진 객체와 중첩 클리핑을 회귀 검증한다. 1,000개 엔티티 120fps·핫패스 0-GC와 실제 OS IME는 계측 또는 수동 검증 결과가 나올 때까지 미검증으로 보고한다.
